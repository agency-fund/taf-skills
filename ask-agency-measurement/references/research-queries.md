# Writing research queries to find what this skill doesn't prescribe

This skill deliberately does not name specific validated scales or fix a single framework. When the user needs those specifics, help them find the evidence — either by running the searches yourself (if you have web search or research tools) or by handing them precise, paste-ready queries to run in their own AI assistant, literature tools, or web search.

These queries work in any general AI tool or search engine, and they get sharper when the user can point the tool at their own context documents (theory of change, product docs, prior instruments, user-research notes) or a corpus they trust.

## What makes a query targeted
A weak query is context-free ("what is a good agency scale?"). A strong one carries four things:
1. **Construct** — the precise form/manifestation, in framework language where useful (e.g., "perceived control / self-efficacy," "Bandura's forethought," "structural agency").
2. **Population and setting** — who, where, what language, what constraints.
3. **Domain** — health, learning, livelihoods, civic, financial, etc.
4. **Use** — what they'll do with it (adapt an item for an in-app micro-survey, build an off-platform battery, code transcripts with a rubric, compare across groups).

## Templates — fill the brackets from the user's answers
- **Find a fitting framework:** "Theories and frameworks of [construct] for [population] in [domain]. For each: what it foregrounds, what it can and can't detect, and its main critiques. Note any that distinguish agency *toward a goal* from agency *in relation to a tool*."
- **Find validated instruments:** "Validated scales measuring [construct] for [population] in [domain]. For each: what it measures, validation sample and setting, number of items, response format, and known limitations in [setting/language]. Cite sources."
- **Adapt for on-platform use:** "From validated [construct] measures, which items could become a 1–2 item in-app micro-survey delivered [at this moment]? Flag items whose framing or response format may not transfer to [setting/language]. Cite sources."
- **Cross-cultural cautions:** "Evidence on social-desirability bias, translation effects, response styles, and norm sensitivity when measuring [construct] among [population]. Concrete design and interpretation cautions, with sources."
- **Build a coding rubric (LLM-as-measure / observation):** "How is [construct] operationalized as observable behaviors or transcript signals? Draft candidate rubric anchors for low/medium/high agency in [domain], with theoretical and empirical sources."
- **Map a framework to measures:** "For [framework], list measures aligned to each component for [population/domain], and flag components with thin measurement coverage. Cite sources."
- **Validation methods:** "Best-practice validation for a [survey/rubric/LLM-annotation] measure of [construct] in [setting], including the smallest credible step for a small team, and how to test measurement invariance across [groups/languages]. Cite sources."

## After the search
Whatever a search surfaces still has to be chosen *for this context and moment* and run through the Step 3 validation checks. Research narrows the field; it doesn't end the work. Note where each instrument or method came from so the user can trace claims back to a source.
