# Choosing how to measure (Step 2)

Use this to ask diagnostic questions and recommend a measurement approach for each part of the defined construct. The tool types are examples; research specifics this skill doesn't prescribe.

## Three decisions, per construct (resolve in this order)
1. **What exactly is measured?** Name it precisely ("perceived control over the next step," not "agency").
2. **On- or off-platform?** On-platform (in-app micro-surveys, interactions, traces): cheap, in-the-moment, large N, but short and low response. Off-platform (surveys, interviews, observation, records): room for validated measures and context, but costlier and smaller N. Strong plans use both.
3. **Which moment in the user journey?** Tie the measure to when the construct is live.

## Menu of tool types (examples)
- **Self-report survey** — felt agency; watch social-desirability/acquiescence and translation; prefer adapting a validated instrument.
- **Observation/rubric** — expressed agency; needs clear anchors and trained raters.
- **Interview/qualitative** — meaning, reasoning, actual use; surfaces constructs you missed.
- **Administrative/outcome records** — objective downstream data for criterion-linking.
- **Digital traces** — behavioral logs; less self-report bias; best when linked to the end goal.
- **LLM-as-a-measure** — judge agency signals across many transcripts at scale; **experimental** — validate and triangulate.
- **Others** — diaries, vignettes, experiments/A-B, behavioral games. A construct that fits none of these is a cue to research.

## Questions that point to a tool
- Internal construct (→ self-report/interview) or behavioral (→ traces/observation/records)?
- How much burden can users bear, and when? (On-platform → one or two items.)
- Can it be linked to a real downstream outcome?
- What's the biggest bias threat, and which tool is least exposed to it?
- Is there a validated instrument to adapt, or must we build (and research) one?

End each cell with: construct → data location → tool → moment → main caution, plus what still needs researching.
